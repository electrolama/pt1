# pt1

pt1 brings several common hardware-debugging functions together on a compact
USB-connected board. It provides extra USB ports, a serial interface, and
software-switchable power for working with target devices.

For an overview, documentation, and usage information, see the
[pt1 project documentation](https://lab.electrolama.com/project/pt1).

## Companion software

[Vicuña](https://lab.electrolama.com/project/vicuna) is Electrolama's
browser-based serial monitor and terminal, with a dedicated pt1 mode for power
control and fault monitoring.
