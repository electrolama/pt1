# Support

For setup and usage questions, begin with the
[troubleshooting guide](documentation/troubleshooting.md) and the
[published pt1 documentation](https://lab.electrolama.com/project/pt1).

When reporting a problem, include:

- PCB revision and enclosure variant;
- host operating system;
- USB cable and power-source details;
- the observed USB devices and serial-port name;
- target wiring and expected load current;
- DTR and RI states, if power control is involved; and
- photographs or logs with secrets and personal information removed.

Use the repository's issue forms for reproducible hardware problems,
documentation defects, and feature proposals. Do not use a public issue for a
private security or safety report; contact the project maintainers through a
private channel listed on the Electrolama website.
